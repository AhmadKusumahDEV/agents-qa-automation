# Projects

Setiap aplikasi yang diautomasi punya satu folder di sini.

    projects/
      saucedemo/     latihan baseline
      go-chat/       menyusul
      atelier/       menyusul

Aturan singkat:

- Satu folder satu aplikasi, huruf kecil tanpa spasi.
- Isi minimal: tests/, resources/pages/, variables/, README.md.
- Konfigurasi masuk environment variable, bukan kode.
- Panduan lengkap ada di docs/menambahkan-project-baru.md.
