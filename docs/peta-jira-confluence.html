Peta Jira, Confluence, dan Scrum

Satu halaman untuk menjawab: ini alat apa, istilahnya apa, dan saya menaruh sesuatu di mana. Dibuat untuk project QAL di madgo.atlassian.net.

Tiga tempat, tiga tugas berbeda

JiraKerja dan status. Story, task, bug, sprint, board, siapa pegang apa.
ConfluencePengetahuan dan bukti. Strategi, panduan, checklist, keputusan.
GitHubKode dan hasil run. File test, CI, log.html, screenshot.
Aturan satu kalimatStatus kerja di Jira, pengetahuan di Confluence, bukti eksekusi di GitHub. Jangan menyalin status harian ke Confluence, dan jangan menaruh dokumen panjang di Jira.

Hierarki issue di Jira

Epic → Story → Sub-task

Bug ditemukan saat menguji story, lalu ditautkan ke story itu.

Contoh: Epic Fondasi QA Manual berisi story Tulis test plan, Susun 24 test case, dan Laporkan 3 bug. Sub-task hanya satu tingkat; kalau butuh tiga tingkat, story-nya yang perlu dipecah.
